# Pipeline Templates（GitHub Projects 版）

## issue-body（sub-repo 鏡像 issue，由 Routine A 建立）

```markdown
<!-- managed by Routine A -->
[高風險警示，若有：> ⚠️ high-risk repo，自動執行限制為 plan-only]

## Description

{任務描述，來自 openspec tasks 分組}

## Tasks

- [ ] {task 4.1 ...}
- [ ] {task 4.2 ...}

## Acceptance Criteria

{來自中央 issue / spec，逐條列出；若無則省略此段}

## Scope Notes

**Scope**: {XS|S|M|L}
**Auto mode**: {plan-only|auto-pr|manual}
**Spec**: `openspec/changes/{change_id}/`

## Links

Parent: daodaoedu/daodao#{central_issue_num}

---
*Auto-created by Routine A (gh-pipeline)*
```

> `Parent:` 行是 Routine C 反查中央 issue 的依據，**格式不可改**。

---

## needs-spec comment（中央 issue，由 Routine A 留言）

```markdown
📋 此卡已標記 `Ready for Dev` + `auto`，但找不到對應 spec：

- Issue body 缺 `OpenSpec: openspec/changes/{slug}/` 註記，或該目錄不存在 tasks.md

請先產 spec（`prd-generation` → `openspec-ff-change`），在 body 補上 OpenSpec 註記後移除 `needs-spec` label，下輪 Routine A 會重新處理。
```

## dispatched comment（中央 issue，由 Routine A 留言）

```markdown
🚀 已 dispatch 到 sub-repo：

- [ ] daodaoedu/{repo}#{n} — {title}（scope:{s}, {auto-mode}）
- [ ] daodaoedu/{repo}#{n} — {title}（scope:{s}, {auto-mode}）

Board Status → In Progress。進度由 Routine C 回報。
```

### L scope — Spec PR（開在 monorepo，加接手指南）

```markdown

**Parent**: daodaoedu/daodao#{central_issue_num}

## Proposal Summary

{詳細說明，含技術風險}

## Tasks

- [ ] {task 1（含 given/when/then）}
- [ ] {task 2（含 given/when/then）}

## Files to Modify

| 檔案 | 原因 |
|------|------|
| {file} | {why} |

## Handoff Guide

1. Checkout issue branch: `git checkout -b feat/{slug} origin/dev`
2. 參考 spec：`openspec/changes/{change_id}/`
3. 依 tasks 逐一實作（TDD）

---
🤖 Spec PR by daodao pipeline (scope:L) | human-coding label added
```

## comments

| 情境 | 留言 |
|------|------|
| 開始處理 | `🤖 Pipeline 開始處理（scope:{scope}, model:{model}）` |
| Token 超限 | `⚠️ Token budget exceeded（used {X} / cap {Y}）。移交人類處理。` |
| 偵測到接管 | `⏸️ 偵測到 \`human-driving\` label，routine 退場（{timestamp}）` |
| Verification 失敗 | `🚨 Verification loop exhausted（2 retries）。移交人類。` |
| Tool 被擋 | `🛡️ Tool \`{tool}\` 不在 allowlist，已拒絕執行。` |
| Phase 1 完成 | `📋 Spec PR 已開：daodaoedu/daodao#{pr_num}。等待 review & merge 後進入 Phase 2。` |
| Phase 2 完成 | `✅ Code PR 已開：daodaoedu/{repo}#{pr_num}。` |
| 高風險拒絕 | `🛡️ high-risk repo（{repo}）強制 plan-only，拒絕開 code PR。` |
| headless 缺資訊 | `⚠️ OpenSpec headless 需要更多資訊：{缺少的欄位}。請補充後手動觸發。` |
| 進度回報（Routine C，中央 issue） | `⏳ Sub-repo 進度：{done}/{total} 完成（{最新完成項}）` |
| 全部完成（Routine C，中央 issue） | `✅ 所有 sub-repo 任務完成：{清單}。Board 已移 Done，待驗收後請手動 close。` |
