# Research / write

1. 用一句話定義讀者、他正在做的事、卡點、讀後行動及本篇新增價值，記入寫作簡報。先查現有文章，避免重寫同一問題；這是單篇研究，不自動擴成內容排程。
2. 只搜尋會改變本文主張的問題。發現候選來源後讀原文，保存共用契約的來源表。工具選擇沿當前工作區規則（Daodao 預設 Groundlane-first）；查完整 callable inventory，限定一次失敗後才用適合的公開搜尋／讀取 fallback，揭露實際路徑。禁用已退役的抓取工具；私有資訊不送公開搜尋。
3. 先以有證據的主張建立大綱，再寫正文。指南給可執行步驟與適用條件；案例必須有當事人授權或清楚標成假想示例；比較保留選擇標準、限制和各方案原始來源。
4. 寫兩語，保留相同核心主張／限制／CTA，不逐字硬翻。雙語缺一語可交草稿，但不能交發布。對實際產品操作查 code／正式入口，不拿行銷假設當功能證據。
5. 寫出支持正文的 title／description；對來源再讀一次，確認數字、時間、引用語境及推論標示。完成後進 verify／review／polish 的適用檢查，不自動提出發布。

輸出：私人 brief + 來源表、兩語 Markdown 草稿與對應文章 ID、未查證清單。只有來源真的支持時才把主張寫成事實。
