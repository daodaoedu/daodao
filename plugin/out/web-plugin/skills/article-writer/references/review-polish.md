# Verify / review / polish

只執行本次要求的模式；review-only 在私人工作區輸出報告，原稿 bytes 不變。

- verify：逐項對照可查證主張與原文，包括數字、時間、產品能力、引用及因果語句。分為 supported／inference／unsupported／unverified，附來源位置；不能以搜尋摘要或第二篇轉述推定原始資料。
- review：檢查讀者問題是否被回答、步驟能否完成、例子是否獲准、來源是否支持、摘要是否誇大、兩語限制及 CTA 是否一致。按問題列位置、影響與具體修法，未獲修訂授權就不寫回原稿。
- polish：修長句、抽象段落、重複但書與模板化轉折；保留原事實與限制，遇到疑似事實錯誤另列，不靠順口文案偷偷改變結論。讀起來自然，不以固定字數／分數作發布條件。

報告分開列事實、覆蓋、可讀性、摘要與雙語。每項可以 pass／fail／unverified／n/a（有理由），並附實際依據。交付前比對 diff，確認修改僅在授權範圍。測試／工具失敗保留失敗，不把機械格式成功當文章品質核准。
