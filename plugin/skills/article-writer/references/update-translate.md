# Update / translate

先讀既有兩語原稿與已發布 baseline，記下 stable id、slug、published_at；修訂保留首發日期與網址。實質內容修訂才填 updated_at，不因建置或單純翻譯重刷日期。欄位規則由共用 validator 判定。

- update：界定過時或錯誤主張，重新讀相應原始來源；只改必要段落，同步另一語與摘要／sources。保留變更理由、受影響主張與需重審範圍。
- translate：先理解讀者可執行行動，保留數字、條件、引用語意與產品限制。可重寫句構與例子，但不得新增英文版獨有的效益或承諾。未有對應產品 UI 翻譯時查實際用語，查不到保留限制。

新稿／翻譯仍是草稿。任何核准後的 bytes 變動都要重新預檢並確認適用審核；不能沿用舊 digest 或自行改核准紀錄。只要求翻譯時不順便發布或改產品程式。
