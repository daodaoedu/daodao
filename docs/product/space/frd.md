## 1. Purpose 目的

「空間」是使用者在島島阿學平台上，容納「一段陪伴旅程」的容器。本頁面提供使用者一個總覽入口，讓其能夠：

- 快速看見自己所在的所有空間（含個人實踐、平台共同挑戰、由發起人主持的邀請制空間），並辨識每個空間目前是否「有進行中的實踐」。
- 從空間清單進入單一空間的子頁，檢視該空間內所有主題實踐的狀態與進度。
- 建立新的空間（邀請他人共學）或新的個人實踐（一個人開始），且此兩種建立流程在使用者心智模型上明確區分。

## 2. Scope 範圍

### 2.1 包含（In Scope）

- 空間主頁（空間.dc.html）：頂部標題與空間數量、空間卡片清單、右下角「新增」浮動按鈕、新增流程的兩擇一面板（開個人實踐 / 開一個空間）。
- 單一空間子頁（例：個人實踐.dc.html、共同挑戰.dc.html、自我覺察練習.dc.html、線上讀書會.dc.html）：主題實踐篩選列（全部／進行中／草稿／未開始／已完成）、主題實踐卡片清單。
- 個人實踐子頁與共同/邀請制空間子頁在資料層與 UI 呈現上的一致性，以及此文件範圍內兩者的差異點。

### 2.2 不包含（Out of Scope）

- 主頁、訊息、管理、通知、我的小島等側邊導覽對應之其他頁面。
- 單一主題實踐（Practice）點入後的內容細節（打卡、靈感、我的實踐庫、人物誌等），僅涵蓋卡片外顯資訊。
- 靈感卡（抽卡）Modal 與新增流程建立完成後的實際後端寫入流程。
- 付費、招募頁、原生金流串接。
- AI 相關功能（含推薦、摘要、分群）於本頁面全數不納入。

## 3. Functional Requirements 功能需求

### 3.1 空間主頁 — 頁面結構與資料

- FR-1.1 頁面頂部顯示標題與使用者目前空間總數，格式為「你的空間 · N 個」。
- FR-1.2 空間清單依固定順序顯示：個人實踐 → 平台主辦之共同挑戰 → 使用者所屬的邀請制/公開空間（依最近有活動時間排序）。
- FR-1.3 空間清單需支援 4 個以上時的直向捲動；本 FRD 不定義每頁筆數上限，但需一次呈現使用者已加入的全部空間。
- FR-1.4 Host view 有複製公開連結、訪客視角按鈕；並可看到對外公開區塊數量。

### 3.2 空間卡片（Space Card）

- FR-2.1 卡片類型為個人實踐、共同挑戰和活動課程。
- FR-2.2 個人實踐卡片的 host 顯示為「我的島」，成員數固定為 1；共同挑戰的 host 顯示為「島島阿學」。
- FR-2.3 活動課程卡片上的 host 則為使用者設定的空間名稱。
- FR-2.4 若個人實踐和共同挑戰空間內存在「進行中」的主題實踐，卡片需顯示狀態標籤「有進行中的實踐」，並以呼吸動畫小點呈現；若無，狀態區塊留白，不使用紅點、驚嘆號或其他警示性視覺。
- FR-2.5 活動課程卡片顯示參與人數及疊加的使用者人頭像。
- FR-2.6 點擊卡片主體導向該空間子頁。

### 3.3 新增流程（Floating「＋」按鈕）

- FR-F1 FAB 位置：右下角浮動按鈕「+ 新增」，於主頁所有捲動位置保持可見。
- FR-F2 建立選單項目：展開後依序顯示：（a）建立主題實踐（副標：開始個人實踐或建立活動模版），（b）建立活動課程（副標：開一個空間，邀請其他人一起）。
- FR-F3 管理者額外項目：對具備管理者 / 島島團隊身份者，額外顯示第三項「共同挑戰（島島團隊）」，副標「全站一起參加的挑戰」；一般使用者不顯示此項。
- FR-F4 選單開關：點擊 FAB 開 / 關選單；點擊選單外區域自動關閉；ESC 可關閉。

## 4. 空間子頁（個人實踐及共同挑戰）

### 個人實踐

- FR-4.1 頁面頂部顯示：空間名稱。
- FR-4.2 頁面提供水平篩選列，選項固定為：全部、進行中、草稿、未開始、已完成；預設選中「進行中」，一次僅可選擇一項。
- FR-4.3 篩選列切換須為前端過濾，不重新載入頁面；當前篩選條件下無資料時，需顯示留白容器與說明文字（例：「這裡還沒有進行中的實踐」），而非隱藏整個清單區塊。

### 共同挑戰

- FR-4.1 頁面頂部顯示：空間名稱。
- FR-4.2 頁面提供水平篩選列，選項固定為：全部、進行中、草稿、未開始、已完成；預設選中「進行中」，一次僅可選擇一項。
- FR-4.3 篩選列切換須為前端過濾，不重新載入頁面；當前篩選條件下無資料時，需顯示留白容器與說明文字（例：「這裡還沒有進行中的實踐」），而非隱藏整個清單區塊。
- FR-4.1(b) 篩選器下方顯示：探索共同挑戰 banner，tagline 提示未來 2 星期內是否有共同挑戰發生；若沒有則顯示「不定期推出新的共同挑戰，下次來看看」。

## 4.1 活動課程

### FR-4.1 空間標頭與成員名單

- FR-1.1 標頭固定顯示於分頁列上方，含空間名稱（主標）與所屬單位／副標（次標）。
- FR-1.2 標頭右側顯示成員總數，以及最多 3 位成員的頭像縮圖（以姓名首字代替，無上傳頭像時亦然）。
- FR-1.3 點擊成員數區塊開啟「成員」彈窗，列出全體成員姓名；發起人於其列右側標示 icon（lucide react user-star）。
- FR-1.4 成員彈窗可點擊關閉鈕或彈窗外遮罩關閉；名單超過可視範圍時於彈窗內捲動，彈窗高度不超過視窗高度的 76%。

### FR-4.2 分頁切換

- FR-2.1 分頁列包含「空間首頁」與「實踐」兩個分頁；「實踐」分頁標籤後方顯示該空間的實踐數量。
- FR-2.2 空間首頁分頁的顯示條件：首頁已建立，且（檢視者為發起人 或 頁面非草稿）。
- FR-2.3 當空間首頁分頁不顯示時，畫面直接落在「實踐」分頁，且不出現任何缺頁提示。
- FR-2.4 頁面處於草稿狀態且檢視者為發起人時，「空間首頁」分頁標籤旁顯示「草稿」標記。
- FR-2.5 切換至「實踐」分頁時，所有進行中的區塊編輯狀態一律結束；已輸入內容保留，不得遺失。
- FR-2.6 分頁狀態不影響瀏覽器上一頁行為；標頭左上返回鍵回到空間列表。

### FR-4.3 首頁建立流程

- FR-3.1 空間尚未建立首頁且檢視者為發起人時，於分頁列下方顯示一張建立引導卡，說明首頁可放的內容，並明確告知「不加也沒關係，空間會直接開在聊天」。
- FR-3.2 引導卡提供「建立頁面」與「先不用」兩個動作。
- FR-3.3 選擇「先不用」後，引導卡收起，改於分頁列右端顯示低調的「＋建立空間首頁」按鈕。此入口必須永久保留，不得因關閉引導卡而永久失去建立首頁的路徑。
- FR-3.4 點擊「建立頁面」或「＋建立空間首頁」，開啟「從哪裡開始？」彈窗，提供兩種起始方式：
  - 帶範例區塊：建立含歡迎詞、怎麼進行、日曆、公告、資源等預設區塊的頁面，內容為可直接改寫的範例文字。
  - 空白頁：建立不含任何區塊的空白頁面，由發起人自行新增。
- FR-3.5 彈窗必須明示兩點：兩種方式之後都可以改；頁面在按下發佈前只有發起人看得到。
- FR-3.6 彈窗提供「取消」，取消後不建立任何頁面。
- FR-3.7 無論選擇哪一種起始方式，建立後的頁面一律進入頁面草稿狀態，並自動切換至空間首頁分頁。
- FR-3.8 一個空間最多只有一個空間首頁。首頁已存在時，建立入口不得出現。

### FR-4.4 頁面層級的草稿與發佈

- FR-4.1 頁面為草稿時，發起人於內容區最上方看到草稿橫幅，文案明確說明「這個頁面還是草稿，只有你看得到」，並提供「發佈頁面」按鈕。
- FR-4.2 按下「發佈頁面」後，頁面轉為已發佈；草稿橫幅與分頁標籤上的草稿標記同時消失。
- FR-4.3 頁面草稿期間，成員完全看不到空間首頁分頁（見 FR-2.2），亦無法透過網址直接進入。
- FR-4.4 頁面發佈後，個別區塊仍可各自維持草稿或排程狀態（見 FR-7）。頁面發佈不等於全部區塊發佈。
- FR-4.5 本版不提供「取消發佈整頁」。若需下架，發起人須逐一將區塊設為草稿。此限制須於驗收會議確認是否接受。

### FR-4.5 區塊系統：組成與新增

- FR-5.1 首頁內容由若干「區塊」垂直排列組成。每個區塊都有標題，以及依型別而異的內容區。
- FR-5.2 範例頁的預設區塊包含：歡迎詞、這裡怎麼進行、公告、日曆、資源。預設區塊可被刪除。
- FR-5.3 發起人於區塊列表末端固定看到「新增區塊」列，提供三種型別：
  - 自由文字：一個可編輯標題與一段可編輯內文。
  - 資源連結：一組「名稱＋網址」的連結列表。
  - 日曆：一組帶日期、時間、地點、連結的活動列表。
- FR-5.4 新增的區塊一律附加於現有區塊之後，並立即進入編輯狀態，游標可直接開始輸入。
- FR-5.5 新增的區塊初始狀態為未發佈的新區塊：成員看不到，且編輯列中同時提供「存成草稿」與「現在發佈」兩個出口。
- FR-5.6 新增的自由文字區塊，標題預設為「新的區塊標題」，內文顯示灰色提示文字「在這裡寫下想告訴大家的事…」。提示文字不得被當作實際內容送出。
- FR-5.7 新增的日曆區塊預設帶一列空白活動；新增的資源區塊預設不帶任何列。
- FR-5.8 「新增區塊」列僅發起人可見，且永遠固定在區塊列表的最後方，不隨排序改變位置。

### FR-4.6 區塊編輯、排序與刪除

- FR-6.1 發起人在每個區塊右上角看到編輯鈕（鉛筆）。成員視角下不得出現任何編輯鈕。
- FR-6.2 進入編輯狀態時，該區塊外圍出現虛線框，並於框線上方顯示浮動編輯列，內含：上移、下移、刪除，以及依狀態顯示的「存成草稿」／「現在發佈」／「存檔」。
- FR-6.3 可同時有多個區塊處於編輯狀態，彼此獨立。
- FR-6.4 任一區塊處於編輯狀態時，內容區上方出現置頂的浮動格式列，提供粗體、斜體、項目清單、插入連結四項，並顯示操作提示「直接點文字就能改，用 ↑↓ 調整區塊順序」。所有區塊都離開編輯狀態時，格式列自動收起。
- FR-6.5 插入連結時彈出網址輸入；未輸入或取消則不套用。
- FR-6.6 上移／下移一次移動一個位置。位於第一個時上移鈕停用，位於最後一個時下移鈕停用；停用狀態須以視覺明確呈現且不可點擊。
- FR-6.7 公告區塊預設釘選於最上方，此時其上移／下移鈕停用；發起人可主動解除釘選，解除後即可自由排序。解除釘選為單向操作，本版不提供重新釘選。
- FR-6.8 點擊刪除鈕不直接刪除，須先跳出確認彈窗，明示「區塊裡的內容會一起移除，這個動作無法復原」，並提供取消與刪除。
- FR-6.9 確認刪除後，該區塊自頁面與右側目錄同步移除。
- FR-6.10 所有內容欄位以離開焦點（blur）為儲存時機，切換分頁或關閉編輯狀態不得造成已輸入內容遺失。

### FR-4.7 區塊層級的草稿、排程與發佈

- FR-7.1 每個區塊有三種發佈狀態，發起人視角下以徽章顯示於區塊底部：
  - 草稿：灰底，僅發起人可見。
  - 排程中：琥珀底，顯示預定發佈時間（格式 YYYY/MM/DD HH:MM 發佈），時間到達前僅發起人可見。
  - 已發佈：主色底，所有成員可見。
- FR-7.2 成員視角下，草稿與排程中的區塊完全不顯示，且不留下任何佔位痕跡。
- FR-7.3 成員視角下不顯示任何狀態徽章。
- FR-7.4 尚未決定去向的新區塊，於編輯列提供「存成草稿」，並於區塊底部提供發佈時間輸入與「現在發佈」按鈕。
- FR-7.5 「現在發佈」會同時清除草稿標記與排程時間，區塊立即轉為已發佈。
- FR-7.6 排程時間若設定為過去時間，視同已發佈。
- FR-7.7 區塊已發佈且無排程時，編輯列顯示「存檔」以結束編輯；此時不再顯示「存成草稿」。
- FR-7.8 已發佈的區塊本版不可退回草稿。此為已知限制，須於驗收確認是否接受；若不接受，將列入 v0.2 補齊。

### FR-4.8 資源連結區塊

- FR-8.1 每一列由左側資源圖示、連結名稱、網址三部分組成；名稱與網址在編輯狀態下皆可直接改寫。
- FR-8.2 編輯狀態下，列表下方顯示「＋新增連結」。點擊後展開一列虛線輸入列，提示文字為「貼上連結，按 Enter」，並自動取得游標焦點。
- FR-8.3 輸入列的行為：按 Enter 建立該列並保持輸入列開啟以便連續貼上；按 Esc 取消；離開焦點時若有內容則建立該列，無內容則收起。
- FR-8.4 系統依網址自動帶入名稱，對照常見服務給出可讀名稱（例：Google 文件、Google 雲端硬碟、Google Meet、Google 表單、Google 日曆、HackMD、Notion、YouTube、Figma、Zoom、Padlet、Miro、Spotify）。
- FR-8.5 網址結尾為 .pdf 時，名稱後方加註「（PDF）」；若非已知服務，則以檔名去除連字號與底線後作為名稱；再不可辨識則以網域名稱作為名稱。
- FR-8.6 自動命名只在名稱為空或仍為預設值「連結名稱」時覆寫，不得覆蓋發起人已自訂的名稱。
- FR-8.7 輸入列下方顯示說明「按 Enter 會自動帶入名稱，之後可以自己改」。
- FR-8.8 每一列可標記其「對應的實踐」，於編輯狀態下以下拉多選（可不選）操作，選項來源為該空間內的實踐。按鈕標籤未選時顯示「實踐」，已選時顯示「N 個實踐」。
- FR-8.9 非編輯狀態下，已標記對應實踐的列在右側顯示資料夾圖示；滑鼠停留時以浮層列出所有對應的實踐名稱。未標記的列不顯示圖示。
- FR-8.10 編輯狀態下每一列右側提供移除鈕，移除該列不需二次確認（區塊本身的刪除才需確認）。
- FR-8.11 名稱與網址過長時以省略號截斷單行顯示，不換行、不撐開版面。
- FR-8.12 若資源與主題實踐關連取消，則任何刪除、修改不做連動。

### FR-4.9 日曆區塊

- FR-9.1 每一列活動包含：標題、開始日期（必填）、結束日期（選填）、開始時間（選填）、結束時間（選填）、地點（選填）、連結（選填）。
- FR-9.2 非編輯狀態的顯示規則：
  - 日期以 YYYY/MM/DD 呈現；有結束日期時呈現為 YYYY/MM/DD–YYYY/MM/DD。
  - 有開始時間時於日期右側顯示時間；有結束時間時呈現為區間。
  - 地點與連結以膠囊標籤呈現於標題下方；連結為 Google Meet 時標籤顯示「Google Meet」，其餘顯示「線上連結」。
- FR-9.3 列表依日期先後排列，並在月份變換處插入月份分隔標籤；跨年時月份標籤須包含年份。
- FR-9.4 編輯狀態下每一列展開為表單，欄位標籤依序為標題、日期、時間、地點、連結；選填欄位須明確標示「選填」。
- FR-9.5 標題為空時，於輸入框內顯示灰色提示「活動名稱」；提示文字不得被當作實際內容送出。
- FR-9.6 地點與連結欄位提供範例格式提示。
- FR-9.7 編輯狀態下提供「＋新增一列」與每列的移除鈕。

### FR-4.10 區塊目錄（右側 TOC）

- FR-10.1 內容區右側顯示置頂的區塊目錄，以短橫線代表每個區塊。
- FR-10.2 目錄項目的名稱直接取自各區塊的標題文字；發起人在編輯標題時，目錄名稱須即時同步。
- FR-10.3 目錄項目順序與區塊實際排列順序一致，隨排序調整即時更新。
- FR-10.4 已刪除、草稿、排程中且對當前檢視者不可見的區塊，不得出現在目錄中。
- FR-10.5 滑鼠停留於目錄項目時顯示該區塊標題。
- FR-10.6 點擊目錄項目平滑捲動至對應區塊，並在頂端保留適當留白，不使標題貼齊視窗上緣。
- FR-10.7 捲動頁面時，目錄自動標示當前所在區塊（該項目加粗、加深）。
