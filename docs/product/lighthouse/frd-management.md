## 1. 目的 Purpose

本功能讓帶領人（發起人／主持人）在一個統一後台中掌握所有進行中活動的全局狀態，並在進入個別場次後，透過儀表板、名單、今日焦點三個功能模組，做出具體的陪伴決策。

設計意圖不是給帶領人一個「監控面板」，而是回答三個核心問題：

1. **這群人整體狀態如何？**——由儀表板回答，呈現打卡量體與節奏，讓帶領人判斷學習容器是否在運作。
2. **誰在這裡、怎麼進來的？**——由名單回答，管理成員邀請、加入狀態與名單維護。
3. **現在我最該關注誰？**——由今日焦點回答，把「該鼓勵的人」與「值得慶祝的時刻」浮現出來，降低帶領人遺漏的可能性。

## 2. 範圍 Scope

### 2.1 涵蓋功能

- **A. 總覽頁（Overview）**：帶領人進入「管理」模組後的首頁，提供所有系列與場次的摘要卡片，一覽全局。
- **B. 場次管理（Cohort Detail）——三個頁籤**：點擊特定場次後進入場次管理介面，頂部頁籤列提供：儀表板、名單、今日焦點、動態（本版不含）、成果（本版不含）。

### 2.2 不涵蓋功能

- 系列與場次的新建流程（含場次設定面板各區段：基本、報名、隱私、實踐、活動主頁）→ 獨立 FRD
- 模板庫（Templates）→ 獨立 FRD
- 組織設定（Organization Settings）→ 獨立 FRD
- 「動態」「成果」頁籤 → 未來版本
- **共同管理者**：與帶領人擁有相同操作權限的成員（在組織設定中新增）

### 2.3 使用者角色

**帶領人（Host / Lighthouse Keeper）**：本功能的唯一使用者。擁有對所屬燈塔下所有系列、場次、參與者名單的讀取與管理權限。

## 3. 功能需求 Functional Requirements

### 3.0 入口

- 使用者可透過點選主頁 sidebar 的「管理」進入此頁面
- 點選左上角島島 logo 即回主頁

### 3.1 總覽頁（Overview）

#### FR-OV-01 頁面標題與導航

- 頁面 H1 標題：「看見一群人如何持續往前」。
- 左側導覽欄（aside）固定顯示燈塔名稱與頭像，導覽列包含：總覽、系列與場次、模板庫、組織設定。
- 當前頁面項目以高亮指示條標記（左側 4px 色條 #16B9B3）。
- 側邊欄可收合：收合後僅顯示圖示（寬度 76px），展開時顯示圖示與文字（寬度 256px）。

#### FR-OV-02 場次卡片列表

以 2 欄 Grid 排列顯示所有場次卡片。每張卡片顯示：

- 狀態標籤（已發佈 / 草稿 / 已封存），對應不同底色（綠底 / 灰底 / 紅底）
- 場次名稱（H2）
- 卡片右上角操作按鈕：編輯場次設定（鉛筆 icon）
- 點擊卡片本體（非按鈕區域）→ 進入該場次管理介面
- 標題列右側有「系列與場次」快速跳轉按鈕

#### FR-OV-03 場次列操作

- 每個場次列項目提供 context menu（⋮）：複製、封存
- 草稿狀態場次額外顯示「發佈」按鈕
- 已發佈場次顯示「編輯」按鈕
- 點擊「管理本場次」箭頭 → 進入場次管理介面

### 3.2 場次管理——頁籤導航（Cohort Tabs）

#### FR-CT-01 頁籤列

- 進入場次管理後，頂部固定顯示橫向頁籤列，包含：儀表板、名單、今日焦點、動態、成果。
- 當前頁籤以深色 chip 樣式（#0D3036 底、白字）標示。
- 「動態」「成果」為未開放頁籤，點擊後顯示「○○ 還在規劃中。」占位文字。
- 頁籤列上方顯示：「返回系列與場次」按鈕 + 場次名稱（H1）+ 編輯按鈕。

### 3.3 儀表板（Dashboard）

#### FR-DB-01 實踐篩選器

- 儀表板頂部顯示水平 chip 列，包含「全部實踐」以及各個別實踐名稱。
- 點擊 chip 切換篩選，選中 chip 以深色樣式標示（data-chip="true"）。
- 切換篩選後，下方所有區塊（KPI 卡、熱度圖、標籤、情緒、走勢、時段、參與者表格）同步更新資料。

#### FR-DB-02 KPI 摘要卡

以 3 欄 Grid 顯示三張 KPI 卡片，每張含圖示、數字、標籤：

- **已加入**：已報名參與者總數
- **已開始**：至少有一則打卡紀錄的參與者數
- **持續行動中（本週）**：本週有打卡紀錄的參與者數
- KPI 卡僅顯示人數計數，不得出現百分比排名、漏斗轉換率或活躍度分數。

#### FR-DB-03 實踐總覽表（僅在「全部實踐」篩選時顯示）

- 標題：「實踐總覽」，附帶日期範圍摘要文字。
- 右上角日期範圍選擇器：起始日、結束日、「全期間」重置按鈕。
- 表格每列呈現一個實踐項目，欄位包含：實踐名稱 + 日期範圍、已開始（人數）、打卡次數（總數）、平均打卡人數、平均打卡字數
- 以圓角卡片列（非傳統表格）排列。

#### FR-DB-04 打卡熱度圖

- 標題：「打卡熱度圖」，副標：「每格代表一天，顏色越深表示當天打卡次數越多」。
- 以 Grid 排列正方形色塊（32px × 32px），每格代表一天。
- 顏色梯度：以 #16B9B3 為深色端、#EDF8F6 為淺色端，依打卡次數線性混色。無打卡日為 #EDF8F6。
- Hover 顯示 tooltip：「○月○日 · N 則打卡」。

#### FR-DB-05 打卡標籤分佈

- 標題：「打卡標籤分佈」，副標：「打卡中最常出現的標籤」。
- 以 Chip 列呈現常見標籤，樣式為 #E7FAF7 底、#0D5B59 文字。

#### FR-DB-06 情緒分佈

- 標題：「情緒分佈」，副標：「打卡時情緒分佈」。
- 以水平長條圖呈現各情緒標籤的次數分佈。
- 每列：情緒名稱 + 數值 + 進度條（#16B9B3 底）。

#### FR-DB-07 打卡走勢

標題：「打卡走勢」，副標：「近 2 週的打卡走勢」。顯示內容：

- 本週打卡總數（大字 highlight）
- 與上週差異 badge（如「比上週 +3 則」），綠色底 chip
- SVG 折線圖：14 天走勢，含面積填色（#EDF8F6）、折線（#16B9B3）、末端圓點
- Hover 每日柱：tooltip 顯示「○月○日 · N 則打卡」
- 底部 x 軸標籤：兩週標籤

#### FR-DB-08 打卡時段

- 標題：「打卡時段」，副標：「偏好在哪些時段打卡（24 小時制）」。
- 跨 2 欄 Grid 顯示長條圖。
- 每根長條代表一個時段區間，高度按比例縮放（max 140px）。
- 長條上方顯示次數，下方顯示時段文字。
- 長條顏色：#16B9B3。

#### FR-DB-09 參與者明細表

- 標題：「參與者」。
- 篩選列：姓名/Email 搜尋框 + 實踐 dropdown + 起迄日期 + 「清除篩選」按鈕 + 筆數統計。
- 表格欄位（可拖曳調整欄寬、可排序）：參與者（排序：名稱）、Email（不可排序）、實踐（不可排序）、開始日（排序）、打卡次數（排序）、留言（排序）、瀏覽（排序）、迴響（排序）
- 預設欄寬：120 / 210 / 210 / 110 / 90 / 70 / 70 / 70 px。
- 排序方式：點擊欄標頭切換升序/降序。當前排序欄以 ▲ 或 ▼ 標示。

### 3.4 名單（Roster）

#### FR-RS-01 邀請成員

左側面板（1.2fr 寬度佔比）：

- 標題：「邀請成員」
- Email 名單文字輸入區：多行 textarea，一行一個 email
- CSV 上傳：file input，僅接受 .csv 格式
- 提示文字：「上傳名單前請確認已取得當事人同意，邀請信只用於本場次。」
- 「預覽名單」按鈕 → 觸發預覽結果區段顯示

#### FR-RS-02 邀請連結

右側面板（0.8fr 寬度佔比），淡綠底卡片：

- 標題：「邀請連結」+ 「複製連結」按鈕
- 當加入開放時：顯示 QR Code 區塊
- 當加入暫停時：提示文字「目前已暫停加入，新成員需要邀請信才能加入。」
- 操作按鈕：「重置加入連結」「暫停加入」/「重新開放加入」

#### FR-RS-03 預覽結果

- 僅在使用者點擊「預覽名單」後顯示。
- 標題：「預覽結果」+ 「寄出邀請」按鈕。
- 列表逐行顯示 email + 狀態備註（如「新邀請」「已存在」等），不同狀態以不同顏色區分。

#### FR-RS-04 成員名單

- 標題：「名單」+ 右上方成員數量摘要。
- 每筆成員資料：暱稱、加入日期/Email 等摘要資訊、狀態標籤（如「已加入」「待確認」「已邀請」等）。
- 狀態標籤使用不同底色 chip 區分：已加入：綠底 chip；待確認 / 已邀請：灰底或其他底色 chip
- 「待確認」狀態額外顯示「重寄」按鈕。
- 所有狀態皆可顯示「移除」按鈕。

### 3.5 今日焦點（Today's Focus）

#### FR-TF-01 頁面說明與子頁籤

- 頁面引導文字：「看看誰需要一點鼓勵，也別錯過值得慶祝的時刻。」
- 子頁籤切換列（pill 樣式，#E7FAF7 底）：兩個子頁籤（「鼓勵」與「慶祝」），點擊切換。
- 選中頁籤以 chip 深色樣式標示。

#### FR-TF-02 鼓勵（Encourage）子頁籤

表格欄位（水平捲動，最小寬度 800px）：

- 參與者（暱稱）
- 實踐（可點擊 → 開啟打卡紀錄側邊抽屜）
- 最後打卡日
- 距離上次打卡（以天數呈現，橘色文字 #A95D00）
- 訊息紀錄（按鈕 → 開啟歷史訊息 modal）
- 送出鼓勵（按鈕 → 開啟訊息撰寫 modal）
- 「實踐」欄標題帶有 info tooltip：「點擊實踐名稱可查看該參與者的打卡內容」。
- 不得在此表格中加入「活躍度分數」「風險等級」或「掉隊警告」等欄位。

#### FR-TF-03 慶祝（Celebrate）子頁籤

表格欄位（水平捲動，最小寬度 840px）：參與者（暱稱）、實踐（可點擊 → 開啟打卡紀錄側邊抽屜）、首次打卡日、值得慶祝的時刻（文字描述）、訊息紀錄（按鈕 → 開啟歷史訊息 modal）、送出訊息（按鈕 → 開啟訊息撰寫 modal）

#### FR-TF-04 打卡紀錄抽屜（Drawer）

- 從右側滑入，固定寬度 min(420px, 92vw)。
- 背景遮罩：rgba(15,48,54,0.28)，點擊遮罩關閉。
- 抽屜標題列：「打卡紀錄」標籤 + 參與者暱稱（H2）+ 實踐名稱 + 關閉按鈕。
- 內容區：逐則顯示打卡紀錄卡片，每張卡片含日期（mono 字體）+ 打卡內容文字。
- 空狀態：「還沒有打卡紀錄。」虛線框。

#### FR-TF-05 訊息紀錄 Modal

- 標題：「與 {名字} 的往來」。
- 逐則顯示歷史訊息卡片，每張含日期 + 訊息內容。
- 空狀態：「還沒有送過訊息。」虛線框。
- 底部關閉按鈕。

#### FR-TF-06 訊息撰寫 Modal

- 標題：「給 {名字}」。
- 訊息範本功能：類別切換（pill）：鼓勵、慶祝；範本下拉選單 + 「存成範本」「刪除（當前範本）」按鈕；選擇範本後自動填入 textarea
- Textarea：可自由編輯訊息內容，placeholder「寫下你想說的話…」。
- 底部按鈕：「取消」（輪廓按鈕）、「送出」（#16B9B3 實心按鈕）。

### 4.6 響應式與無障礙
